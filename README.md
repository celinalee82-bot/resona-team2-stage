## 레조나 화면을 스크린에 받기 (로컬 버전만)

- **레조나 화면 받기**: 화면 공유 창에서 레조나 출력창·탭·화면 전체를 고르면 실시간으로 LED 스크린에 들어감 (시뮬레이터를 레조나와 같은 컴퓨터에서 열 때)
- **캡처 장치**: 레조나 컴퓨터 HDMI → 캡처보드 → 이 컴퓨터. 내장 카메라가 아닌 장치를 먼저 고르고, 여러 개면 목록에서 선택
- 링크 버전은 브라우저 보안 때문에 둘 다 안 됨

|---|---|---|---|

| 2 | 왼쪽 | 1.30 : 1 | **1440 × 1105** |

- 「레조나 출력 → 스크린」 줄마다 고름: **기본(그림·영상)** / **화면 공유로 받기**(레조나 출력창 N 선택) / **캡처 장치**(처음에 「캡처 장치 목록 불러오기」 → 장치별 선택)

- 출력이 끊기면 그 줄은 자동으로 기본으로 돌아감
- **영상 파일 불러오기…** (중앙·왼쪽·오른쪽만) — 스크린마다 다른 영상을 루프로
- **루프 속도 노브** (중앙·왼쪽·오른쪽) — 위로 끌면 빠르게 / 아래로 끌면 느리게 (0.1×~4×) · 마우스 휠도 됨 · 더블클릭 = 1× · 영상 파일이 들어간 스크린에서만 켜짐(나머지는 흐리게)

## 영상 띄우기

- 화면에 영상 파일을 **끌어놓기**, 또는 왼쪽 **「영상 불러오기」**
- 주소로: `stage_sim.html?video=<경로>` (예: 극아타×버닝버니즈 영상 `../../04_참고자료/극아타_버닝버니즈/...mp4`)
- 영상이 들어가면 전광판·TV·셔터에 깔린다. **A** = LED마다 각자 꽉 채움 · **B** = 세 LED에 영상 한 장이 걸쳐짐
- 구동 트랙이 약하면 살짝 어두워지고, 박마다 하얗게 번쩍 → 영상도 음악에 반응
- `V` = 영상 ↔ 그림 전환 · 큐 바뀔 때 TV에 0.7초 컬러바

## 프로젝터로 무대 화면만 출력

- **「무대 화면 출력창 (프로젝터)」** (`P`) — 패널 없이 무대만 나오는 새 창. 프로젝터(확장 모니터)로 끌어다 놓고 **더블클릭 = 전체화면**. 조작은 원래 창에서, 출력창은 실시간으로 따라감 (마우스 가만두면 커서·안내 숨김)
  - 처음에 팝업이 막히면: 크롬 주소창 오른쪽 팝업 차단 아이콘 → 「항상 허용」 → 다시 누르기
  - **원래 창은 최소화하거나 완전히 가리지 말 것** — 크롬이 그리기를 멈추면 출력도 멈춤
  - 프로젝터 비율(보통 16:9)과 원래 창 비율이 다르면 위아래나 좌우에 검은 여백이 생김 → 원래 창을 16:9 비슷하게
- **「이 창을 출력 화면으로」** — 예비. 패널 숨기고 이 창 자체를 전체화면 (미러링으로 쓸 때). `H` 패널 다시 · `Esc` 전체화면 끄기
- 출력창은 시작.command로 연 로컬 버전에서 쓰기 (링크 버전은 새 창이 막힐 수 있음)

## 3D 시점

- 마우스 드래그 = 회전 · 휠/트랙패드 = 줌 · 오른쪽 드래그(두 손가락) = 이동
- `0` 정면 · `9` 객석(기본) · `8` 사선 · `7` 위에서 · `O` 자동 회전 (부스용)
- 3D 무대 치수: `SCREENS`(스크린 자리·깊이·꺾임) · 「무대 안 골목 세트」 블록(`ROOM` 오렌지 방 · `neonSign()` 네온) · `POLE_L`/`POLE_R`(전봇대, 일부러 다르게)
- 스크린 A = 중앙 따로 + 좌우는 거울상 · B = 세 스크린이 한 장 · 곡 3 = 분홍 와이어프레임 도시

## 셔터·커튼 — 포스터 + 이퀄라이저

- **왼쪽 셔터** = 드럼 레벨 미터 (셔터 살이 아래→위로 차오름, 분홍→흰) · **오른쪽 오렌지 방 커튼** = 12줄 스펙트럼 (베이스→고음, 청록→흰)
- **포스터** = 극아타 공연 전단(영어) + 스프레이 그래피티 「tigers!」
- 버튼: 「포스터」·「이퀄라이저」 켜기/끄기 · 섞는 방식
  - **나누기** (기본): 포스터는 사람 키 높이까지, 그 위가 이퀄라이저 · **B 큐엔 이퀄라이저가 끝까지 덮음**
  - **겹치기**: 포스터 전체 + 이퀄라이저는 살 틈으로 새는 빛(약하게)
  - **큐 따라**: A 큐 = 포스터 / B 큐 = 이퀄라이저
- 전식을 끄면 이퀄라이저도 꺼짐
- **포스터를 내 이미지로**: 「왼쪽 셔터 이미지」·「오른쪽 커튼 이미지」 (또는 화면 왼쪽/오른쪽 절반에 끌어놓기) · 「기본 포스터로」 되돌리기
  - 권장 크기: **셔터 1400×1190 px (1.18:1)** · **커튼 1520×1170 px (1.30:1)**
  - 「나누기」 모드에선 아래쪽 약 52%만 보임 → **중요한 내용은 아래 절반에** · 투명 PNG면 셔터 살이 비쳐 진짜 붙인 느낌

- **빔 엣지 슬라이더** (하드 ↔ 소프트) — 하드 = 윤곽 또렷·폭 좁음(포커스 빔) / 소프트 = 가장자리 번짐·폭 넓음(프로스트 워시). 무빙 20 + 업라이트 8 전부
- **무빙 패턴 7종** — 바꿀 때 빔이 부드럽게 돌아감
  - 자유(쓸기) · **왕관**(뒷줄 위로 솟는 끝 + 업라이트 짝이 높낮이 다른 봉우리 Λ + 앞줄 아래 띠) · **선버스트**(무대 뒤에서 하늘로 햇살) · **X 크로스** · **커튼**(수직) · **센터**(보컬 한 점) · **파도**(왼→오 차례로)
- **패턴 자동** — 16박마다 다음 패턴

## 무빙 색 · 조도 (3그룹)

| 그룹 | 대수 | 컨트롤 |
|---|---|---|
| 앞 트러스 무빙 | 10 | 컬러 휠 · 곡 색 따라 · 조도 0~100 |
| 뒤 트러스 무빙 | 10 | 〃 |
| 바닥 업라이트 | 8 | 〃 |

- 조도 = 기본 밝기. 음악 반응(박자 번쩍임 등)은 그 조도 안에서 움직임
- 휠로 고르면 거의 그 색 그대로 / 곡 색 따라면 흰빛이 섞인 곡 색

## 응원봉 색

- **컬러 휠** — 누르거나 끌면 그 색으로
- **곡 색 따라** — 큐(곡) 색을 따라감 (기본)
- **오토 (응원봉 연출)** — 중앙 제어 응원봉처럼 패턴이 32박마다 바뀜: 색 파도 → 무대에서 퍼지는 링 → 좌우 교차(박마다) → 반짝임. 지금 패턴은 왼쪽 아래 상태줄에 표시

## 조작

| 키 | 동작 |
|---|---|
| `1` `2` `3` | 곡 |

## 고칠 곳

- **LED 자리** — `stage_sim.html` 맨 위 `SLOTS` · `BULBS` (가상 좌표 1000×560). 미니어처 마스크 구멍과 같은 숫자로 맞춘다.
- **회색 라인 세트** — `setLines()` (전봇대·셔터 상자·비계·계단·건물 프레임) · 전선은 `drawWires()`
- **큐 이름·구동 트랙** — `SONGS`.
- **그림** — `paintGlitch` · `paintSky` · `paintScribble` (영상이 없을 때 쓰는 임시 그림).
